# HabitAway

**قدرت گرفته از Benyamin Rasouli**  

HabitAway یک اپلیکیشن مدیریت عادت‌ها و روتین‌های روزانه است که به شما کمک می‌کند عادت‌های مثبت خود را دنبال کنید و انگیزه‌تان را حفظ کنید. این پروژه با **Kotlin، Jetpack Compose، و Room Database** توسعه داده شده است.

---

## ویژگی‌ها

- ایجاد و مدیریت عادت‌ها  
- صفحه اصلی جذاب با ناوبری ساده  
- پروفایل کاربری و تنظیمات شخصی  
- صفحه مطالعه و دنبال کردن چالش‌ها  
- ذخیره‌سازی امن اطلاعات کاربر با Room و Preferences
